# Art portfolio

My game art portfolio, hosted with GitHub Pages.

## Files
- `index.html`: the page content (name, text, sections, links)
- `style.css`: colors, fonts and layout. The palette lives in the `:root` blocks at the top.
- `script.js`: the interactions (hero flashlight, wireframe reveal, draggable sketches)
- `images/`: put artwork here and point to it from `index.html`

## Edit the placeholders
- Replace "Your Name" in `index.html` (the title, the nav, the `h1` and its `data-t` attribute, and the footer).
- Write your own About paragraph.
- Update the email, ArtStation and Instagram links in the About section.

## Preview locally
Open the folder in VS Code, install the Live Server extension, then right-click `index.html` and choose "Open with Live Server".
